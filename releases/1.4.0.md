# Red 1.4.0 — 28 July 2026

Customer-facing release notes for the public Red MCP server.

## Highlights

- **Multi-line sales invoices** — Red improved support for invoices containing several lines. It checks that each line contains the required information, that net, VAT and total amounts add up correctly, that the invoice total matches its individual lines, that appropriate Sales VAT categories are used, and that incomplete or placeholder product details are caught before saving. Validation errors explain which part of the invoice needs correction.
- **Company-readiness checks** — Red added a more complete company-readiness check covering areas such as the company’s financial year, whether a proposed transaction date falls within that financial year, Sales VAT rates, Sales Analysis categories, products, sales representatives, and other setup required for sales, purchases and reports. Red can report that a company is ready, ready with warnings, not ready, or experiencing a connection problem. Required problems are separated from recommendations, so users can distinguish blockers from optional setup improvements.
- **Connection reliability** — Red was improved so that it retains the company connection when the AI client retries a request, marks an API key invalid only following a genuine authentication failure, does not clear an otherwise valid connection because of an unrelated request failure, and reduces unnecessary requests for customers to reconnect. This addressed cases where a company could connect successfully and use some Red features, then later receive an incorrect invalid-or-expired API-key message when listing sales invoices.

### Example requests

**Multi-line sales invoices**

- “Create a sales invoice with multiple product lines.”
- “Create an invoice using a generated reference.”
- “Check why this invoice cannot be created.”
- “Preview this invoice before saving it.”

**Company-readiness checks**

- “Is this company ready to create sales invoices?”
- “Check whether this company is ready for sales, purchases and reports.”
- “What setup is missing from this company?”
- “Why is this company only ready with warnings?”
- “Are all my companies set up in the same way?”

## Safety reminders

- Multi-line invoices are checked before they are saved.
- Company-readiness warnings do not themselves change company setup.
- Write actions require preview and explicit confirmation.
