# Red 1.3.0 — 21 July 2026

Customer-facing release notes for the public Red MCP server.

## Highlights

- **Helpful resources** — Red added more complete support answers using official Big Red Cloud resources. It can provide relevant Freshdesk support articles, step-by-step guidance based on official articles, secure “View image” links for relevant Freshdesk screenshots, matching YouTube training videos under a Sources section, additional written articles when customers asked for more reading, and the option to continue into a supported Red action, with a preview before anything is saved.
- **YouTube training videos** — Red began including relevant Big Red Cloud training videos when there was a strong topic match. Videos appear under Sources → Videos. Red avoids including a video when no sufficiently relevant match exists. At the time of this release, videos from 2024 onward had been included; that was the available content then, not a permanent restriction.
- **Support knowledge base** — Red’s support guidance was updated alongside the resource-search functionality.

### Example requests

- “How do I create a sales invoice?”
- “How do I use the Cash Book?”
- “How do I reconcile my bank account?”
- “What training videos are available?”
- “Do you have any written sources I can read?”

## Safety reminders

- Help answers may provide official resources and links.
- Supported accounting actions still require preview and explicit confirmation.
- Asking for instructions should not itself authorise a change to company data.

- Package / MCP server version: **1.3.0**
