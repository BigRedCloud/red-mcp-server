# Red 1.6.0 — 18 August 2026

Customer-facing release notes for the public Red MCP server.

## Highlights

- **Quotes** — clearer confirmation previews (including generating a sales invoice from a quote), safer quote updates, and more reliable totals rounding.
- **Cash receipts and cash payments** — more reliable VAT handling, ledger amounts preserved when updating receipts, and safer correction of cash payments.
- **Prior-year dates** — a date outside the current financial year is a warning, not an automatic refusal. After confirmation, Red attempts the supported action. If Big Red Cloud rejects the date, the actual response is reported.
- **Account history** — Red can identify the document type behind a customer or supplier account-history line before choosing the matching lookup or change.
- **Safer undo, reverse, and correct** — asking to undo or reverse a change is treated as planning first. Red explains the supported options in plain language, does not invent reversing entries, and still requires preview and confirmation before any further change.
- **Session activity and support diagnostics** — clearer session activity summaries, plus a downloadable support diagnostic for one connected company. Credentials, tokens, and connection secrets are excluded.
- **Claude reliability** — more reliable discovery of company connection, routing, and help tools on Claude.

## Safety reminders

- Company API keys are never entered in chat.
- Write actions still require preview and explicit confirmation.
- Asking to undo or reverse a change is not permission to post. Red shows the supported options first.
- Assistants and MCP clients obtain `routeToken` values; end users do not provide them.
