# Red 1.2.0 — 9 July 2026

Customer-facing release notes for the public Red MCP server.

## Highlights

- **Platform availability** — Red was made available for Claude, ChatGPT and Vibe/Mistral. Customers continued using the hosted Red MCP address.
- **Company connection flow** — Red began validating company credentials before confirming a connection. Invalid or expired credentials are rejected before they are stored. In a multi-company attempt, Red shows which companies connected successfully and which failed, so one unsuccessful company no longer causes the whole attempt to be treated as failed.
- **Connection status and expiry** — Red can explain the configured connection duration, remaining connection time and the timezone used for expiry information. At the time of this release, production connections were configured for approximately four hours, and expiry information used the configured Dublin timezone.
- **Sales-invoice safety** — Red requires the gross/net price basis where necessary, blocks placeholder product identifiers before preview or posting, prevents purchase VAT categories from being used on sales invoices, defaults invoice notes appropriately rather than using a product name, and includes delivery information only when the user supplied it. These checks reduce incomplete or incorrectly classified invoices.

## Safety reminders

- API keys must be entered only through Red’s secure connection page, not in chat.
- Write actions require a preview and confirmation.
- Red validates company credentials before storing a successful connection.
