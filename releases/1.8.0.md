# Red 1.8.0 — 2 October 2026

Customer-facing release notes for the public Red MCP server.

This release adds production support for using Red with Microsoft 365 Copilot. Existing ChatGPT, Claude and Mistral integrations continue to use the normal Red endpoint.

## Highlights

- **Microsoft 365 Copilot** — Red can be used as a Microsoft 365 federated connector at `https://red.bigredcloud.com/mcp/copilot`.
- **Read-only Copilot accounting** — The Microsoft 365 Copilot interface is currently read-only. Copilot can search and retrieve supported Big Red Cloud information, but it does not create, update, delete or email accounting records. Create, update and delete remain available on `https://red.bigredcloud.com/mcp` where the deployment enables them.
- **Microsoft-owned company connections** — a Copilot user signs in with an organisational Microsoft account, then connects the Big Red Cloud companies they are authorised to use. One Microsoft user can connect more than one company. Those connections stay with that user.
- **Company management** — users can add a company, replace a company credential, or disconnect one company from a secure management page. Disconnect asks for confirmation. The normal Red connection page can also manage companies already connected in that flow, including adding companies manually or from a CSV.
- **Larger Copilot results** — searches and reports return bounded pages, and Copilot can continue a query without losing the selected company or search.
- **Aged balances and allocations** — Copilot can retrieve supported aged balances and allocation information.
- **Help in Copilot** — Copilot can retrieve official Big Red Cloud help resources. Help questions do not require a connected company.
- **Nominal reports** — grouped nominal reports follow the current Big Red Cloud response format more reliably. Copilot nominal and ledger queries use the same bounded-result behaviour.
- **Reliability** — Microsoft sign-in continues to work when Microsoft rotates signing keys. YouTube help-catalogue notifications are checked for authenticity before a catalogue sync. Diagnostic logging stays off unless an operator turns it on.

## Compatibility

`https://red.bigredcloud.com/mcp` remains the full Red integration used by ChatGPT, Claude and Mistral. Existing integrations continue to use this endpoint and retain the existing preview-and-confirmation workflow for supported write actions.

`https://red.bigredcloud.com/mcp/copilot` is a separate read-only interface for Microsoft 365 Copilot. Existing integrations do not need to move to it.

Company API keys are still entered only on Red’s secure connection page, never in chat.
