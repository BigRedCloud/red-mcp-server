# Red 1.5.0 — 5 August 2026

Customer-facing release notes for the public Red MCP server.

## Highlights

- **Action reliability** — Red became more reliable for creating, updating, deleting, emailing and processing batch requests. It retains the requested action while checking records and preparing previews, carries the correct request into confirmation, recognises short confirmations such as “yes” or “delete it” more reliably, keeps actions linked to the correct company, and prevents an action prepared for one company from being reused against another.
- **Company connections** — Secure connection instructions were clarified, including the distinction between the secure connection link and the confirmation code. Credentials continue to be entered only on the secure page, with a **Copy message for chat** option on the success page. Red became better at retaining a valid company connection when an AI platform retried a request or started another tool session.
- **Help questions versus accounting actions** — Red became better at distinguishing “How do I create a sales invoice?” as a help request from “Create a sales invoice.” as an accounting action. This reduced the chance of a request for instructions starting an action.
- **BRC Edu and webinar content** — Red improved matching customer questions to relevant Freshdesk, YouTube and webinar resources, fallback guidance when no exact resource was available, and synchronisation of supported YouTube and webinar content.
- **Customer guidance** — Red added clearer guidance when required information was missing, confirmation was needed, company setup needed checking, a request could not be completed safely, or a relevant help resource was available.
- **Public discovery** — Red was listed on the public **MCP Register** for discovery. Registration does not change connection behaviour or reliability.
- **Email subjects** — Email subject lines are controlled by **Big Red Cloud** where the API does not expose a subject override. Red does not set invoice email subjects.

## Safety reminders

- Company API keys are never entered in chat.
- Write actions still require preview and explicit confirmation.
- Asking for instructions is not permission to change company data.

## Version
